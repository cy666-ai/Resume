# 收简历

在 Boss 直聘网页上批量收取候选人简历。

## 使用方法

```
/收简历
```

## 功能说明

此 skill 会自动在 Boss 直聘"单聊"页面批量操作：
1. 打开 https://www.zhipin.com/web/chat/geek/manage_v2
2. 使用 Cookie 自动登录
3. 在当前页，依次点击每个候选人的 **沟通** 按钮
4. 在弹出的页面中点击 **求简历** 按钮
5. 在弹出的确认框中点击 **确定**
6. 关闭弹窗，继续处理下一个候选人
7. 当前页全部操作完成后，自动切换到下一页
8. 重复上述操作，直到简历全部索取完毕或无更多候选人

## 执行流程

### 步骤1：环境检查
- 确认 Python 3.8+ 已安装
- 安装依赖：`pip install playwright` 和 `playwright install chromium`

### 步骤2：启动浏览器
- 运行 `python 收简历工具/collect_resumes.py`
- 使用 Playwright 启动 **Edge 浏览器**（非无头模式，以便观察操作过程）
- 设置 Cookie 实现身份认证

### 步骤3：自动化操作
- 打开目标页面
- 等待页面加载完成
- 循环处理每个候选人

### 步骤4：输出结果
- 统计成功索取简历的数量
- 输出操作日志

## 注意事项
- 需要保持网络通畅
- 操作过程中请勿关闭浏览器窗口
- 如果弹出验证码，需要手动处理
- 如果 Cookie 过期，程序会暂停等待手动登录
- 建议控制操作速度，避免被反爬机制限制
