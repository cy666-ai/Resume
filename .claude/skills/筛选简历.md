# 筛选简历

根据岗位要求筛选简历并生成匹配度分析报告。

## 使用方法

```
/筛选简历 <简历路径>
```

参数：
- `简历路径`：简历文件路径或包含简历的文件夹路径（默认为 `./简历/`）

## 功能说明

此skill会：

1. **读取岗位要求**：从当前目录的 `岗位.md` 文件读取职位描述和要求
2. **解析简历文件**：支持以下格式
   - PDF文件 (.pdf)
   - Word文档 (.docx, .doc)
   - 纯文本文件 (.txt, .md)
3. **提取关键信息**：
   - 基本信息（姓名、联系方式）
   - 教育背景
   - 工作经历
   - 技能列表
   - 项目经验
4. **匹配度分析**：将简历内容与岗位要求进行对比，生成匹配报告
5. **输出结果**：生成结构化的分析报告

## 工作流程

执行此skill时，按照以下步骤操作：

### 步骤1：读取简历文件并提取岗位信息
- 如果参数是文件路径，直接读取该文件；如果是文件夹路径，扫描所有简历文件
- **关键：从简历文件名中提取应聘岗位信息**
  - 简历文件名格式为 `【岗位名称_地点 薪资】姓名 工作年限.pdf`
  - 例如 `【智能驾驶实车测试工程师(A99552)_上海 20-40K】郭宝才 3年.pdf`
  - 提取 `【】` 中的内容，第一部分即为岗位名称，如 `智能驾驶实车测试工程师(A99552)`
  - 如果文件名不包含岗位信息，则通过简历内容分析判断

### 步骤2：读取岗位要求
- 读取当前目录下的 `岗位.md` 文件
- **根据步骤1提取的岗位名称，在岗位.md中定位对应的岗位描述和要求**
- 例如提取到 `智能驾驶实车测试工程师(A99552)`，则查找 `1.智能驾驶实车测试工程师(A99552)` 对应的内容
- 如果岗位名称能对应多个子方向（如行泊方向、主动安全、基建），则分别提取各子方向要求
- 提取关键职位要求和技能要求，识别必需技能和加分项

### 步骤3：解析简历内容
- 根据文件类型选择合适的解析方式
- 提取简历中的结构化信息
- 识别关键技能和经验

### 步骤4：匹配分析（按岗位分组）
对每份简历进行以下分析：
- **技能匹配度**：将候选人技能与步骤2找到的对应岗位要求进行对比
- **经验相关性**：评估工作经历与该职位的相关性
- **教育背景**：检查学历要求是否满足
- **综合评分**：给出整体匹配度评分（0-100分）

### 步骤5：生成报告（**按岗位分组输出**）

生成CSV格式报告，文件名格式为 `简历分析报告_YYYYMMDD_HHMMSS.csv`。

**报告结构：**

**第一部分：候选人总览（按岗位分组，组内按综合评分降序）**

每个岗位为一个独立表格，格式：

| 岗位名称 | 候选人 | 工作年限 | 技能匹配度 | 经验匹配度 | 教育匹配度 | 综合评分 | 推荐等级 |
|----------|--------|----------|------------|------------|------------|----------|----------|

**第二部分：详细分析（按岗位分组）**

每个岗位下，列出该岗位所有候选人的详细分析：
- 基本信息
- 技能匹配度（匹配技能、缺失技能、额外技能）
- 经验匹配度分析
- 教育背景匹配度
- 综合评分和建议

**第三部分：岗位要求对照（按岗位分组）**

每个岗位单独一张对照表，列出该岗位的关键要求及各候选人的匹配情况

### 岗位匹配规则

从简历文件名提取岗位时，使用以下规则匹配岗位.md中的岗位：

1. **精确匹配**：文件名中的岗位名称直接对应岗位.md中带编号的标题（如 `1.智能驾驶实车测试工程师(A99552)`）
2. **模糊匹配**：如果精确匹配失败，使用关键词匹配（如"实车测试"、"数据测试"等）
3. **多子方向合并**：如果岗位.md中同一岗位有多个子方向描述（如行泊方向、主动安全、基建），应合并为该岗位完整的要求集进行匹配

## 报告格式说明

- 文件名：`简历分析报告_YYYYMMDD_HHMMSS.csv`
- 示例：`简历分析报告_20260603_185711.csv`
- 保存位置：当前工作目录
- 使用UTF-8编码（带BOM），Excel可直接打开

## 示例

```
/筛选简历 ./简历/
```

这将处理 `简历` 文件夹下的所有简历文件，并生成匹配报告。

## 注意事项

- 确保简历文件可读（非加密、非损坏）
- PDF解析可能需要较长时间，请耐心等待
- 如果简历格式不规范，提取结果可能不准确
- 建议对每份简历进行人工复核后再做最终决定
