# 筛选简历使用说明

本说明用于指导如何使用「筛选简历」skill，对 BOSS 直聘下载的简历进行自动筛选、评分、生成报告，并按结果归档。

## 使用前准备

### 1. 填写岗位要求

打开以下文件，填写或更新本次要筛选的岗位要求：

```text
.claude/skills/筛选简历/references/岗位.md
```

建议每个岗位单独成段，包含：

- 岗位名称
- 工作内容
- 任职要求
- 必需技能
- 加分项
- 学历、经验年限等要求

> 简历筛选会根据简历文件名中的岗位名称，去 `岗位.md` 中匹配对应岗位要求。

### 2. 从 BOSS 直聘下载简历

从 BOSS 直聘下载候选人简历，文件格式支持：

- PDF：`.pdf`
- 图片：`.jpg` / `.jpeg`

请将下载好的简历放到项目根目录下的：

```text
简历/
```

注意：只处理 `简历/` 目录根层级的 PDF/JPG 文件，不会递归处理子文件夹。

### 3. 确认简历文件名包含投递岗位

建议保留 BOSS 下载时的默认文件名，确保文件名中包含候选人投递岗位。

推荐格式示例：

```text
【智能驾驶实车测试工程师(A99552)_上海 20-40K】张三 5年.pdf
【数据测试实习生_上海 150-200元/天】李四 应届生.jpg
```

skill 会优先从 `【】` 中提取岗位名称，再与 `岗位.md` 中的岗位要求进行匹配。

如果文件名不包含岗位信息，系统会尝试从简历内容中判断，但准确率会降低。

## 执行筛选

打开 Claude Code，输入：

```text
筛选简历
```

或使用 slash command：

```text
/筛选简历
```

默认会自动处理：

```text
./简历/
```

如果需要指定其他路径，也可以输入：

```text
/筛选简历 ./简历/
```

## 自动执行流程

执行后，skill 会自动完成以下操作：

1. 读取 `简历/` 根目录下的 PDF/JPG 简历
2. 从简历文件名中提取候选人投递岗位
3. 读取 `岗位.md` 中对应岗位的任职要求
4. 提取简历文本内容
   - PDF 使用 `pdftotext -raw`
   - JPG/JPEG 使用 OCR 识别
5. 清洗 BOSS 直聘简历中的 hash 混淆字符
6. 根据岗位要求进行技能、经验、教育背景匹配评分
7. 查询飞书招聘人才库，判断候选人是否已进入人才库
8. 生成 CSV 格式筛选报告
9. 记录本次筛选名单到 `已投简历名单.md`
10. 按筛选结果归档简历文件

## 输出结果

筛选完成后，会在项目根目录生成：

### 1. 简历分析报告

文件名格式：

```text
简历分析报告_YYYYMMDD_HHMMSS.csv
```

报告内容包括：

- 筛选统计摘要
- 候选人总览
- 候选人简述
- 岗位要求对照
- 总结建议

CSV 使用 UTF-8 BOM 编码，Excel 可以直接打开。

### 2. 已投简历名单

文件：

```text
已投简历名单.md
```

用于持续记录每次筛选过的候选人，避免重复处理。

### 3. 简历归档目录

本次处理的简历会移动到：

```text
简历/筛选结果_YYYYMMDD/
```

归档规则：

```text
简历/筛选结果_YYYYMMDD/
├── 合格简历/
│   └── <岗位名>/
└── 不合格简历/
    ├── <岗位名>/
    └── 已进入人才库/
        └── <岗位名>/
```

说明：

- 评分达到合格阈值的简历会进入 `合格简历/`
- 评分低于合格阈值的简历会进入 `不合格简历/`
- 已在飞书人才库中的候选人会单独归档到 `不合格简历/已进入人才库/`
- 无法匹配岗位的简历会归档到 `无岗位` 分组

## 使用建议

1. 每次筛选前，先确认 `岗位.md` 中的岗位要求是最新的。
2. 从 BOSS 下载简历后，不要随意修改文件名，尤其不要删除岗位名称。
3. 简历文件请直接放在 `简历/` 根目录，不要放进子文件夹。
4. PDF 简历识别效果通常优于截图或图片简历。
5. 自动评分仅用于初筛，最终是否面试建议人工复核。
6. 如果报告中显示人才库查询失败，通常不影响评分和归档，只需要人工确认是否已投递过。

## 快速示例

完整使用流程：

1. 在 `岗位.md` 中写入岗位要求
2. 从 BOSS 直聘下载候选人 PDF/JPG 简历
3. 将简历放入 `简历/` 目录
4. 确认文件名中包含投递岗位
5. 打开 Claude Code
6. 输入：

```text
筛选简历
```

7. 等待自动生成报告和归档结果
